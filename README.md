# 🔐 أمان | AMAN

**أمان safety** هو تطبيق خزنة رقمية محلية مخصص لنظام Windows، لحفظ وإدارة البيانات الحساسة مثل كلمات المرور، أسماء المستخدمين، مفاتيح API، الرموز السرية، التراخيص، الشهادات والملاحظات الخاصة.

تم تصميم التطبيق للعمل محلياً على جهاز المستخدم مع التركيز على سهولة الاستخدام، الخصوصية، التنظيم، وإمكانية العمل دون الاعتماد على خدمة سحابية خارجية.

> **تصميم : عبدالله المخلافي 2026**

---

## 📌 نبذة عن المشروع

تم تطوير **safety** ليكون خزنة مكتبية عملية وآمنة تساعد المستخدم على تنظيم بياناته الحساسة في مكان واحد بدلاً من الاحتفاظ بها في ملفات نصية، دفاتر، متصفحات أو أماكن متفرقة.

التطبيق مبني باستخدام:

- React
- TypeScript
- Vite
- Tauri 2
- Rust
- SQLite / sql.js
- Windows Native File Storage

ويتم تجميعه كتطبيق Windows مستقل باستخدام Tauri.

---

## ⚡ تثبيت سريع للمستخدم

1. نزّل حزمة الإصدار `AMAN-Windows-v2.0.0.zip`.
2. فك الضغط عن الملف في أي مجلد.
3. شغّل ملف التثبيت الموصى به: `AMAN_2.0.0_x64-setup.exe`.
4. اتبع خطوات معالج التثبيت السريع.
5. افتح **AMAN** من قائمة ابدأ (Start) أو سطح المكتب.
6. أنشئ رمز PIN الخاص بك وابدأ بإضافة وتنظيم سجلاتك بأمان تام.

# 💻 كيفية تثبيت AMAN على جهاز Windows

يتم توزيع تطبيق **AMAN** كبرنامج Windows مستقل، ولا يحتاج المستخدم النهائي إلى تثبيت Node.js أو Rust أو أدوات التطوير.

بعد نجاح عملية البناء، يتم توفير ملفات التثبيت الخاصة بنظام Windows ضمن حزمة الإصدار أو GitHub Actions Artifact.

---

## 📥 1. الحصول على ملف التثبيت

يمكن الحصول على ملفات التثبيت من GitHub Actions:

```text
GitHub
→ Actions
→ Windows Tauri Build
→ آخر تشغيل ناجح
→ Artifacts
→ AMAN-Windows-v2.0.0
````

قم بتنزيل ملف الـ Artifact ثم فك ضغطه.

قد تحتوي الحزمة على أكثر من نوع من ملفات التثبيت، مثل:

```text
AMAN_2.0.0_x64-setup.exe
AMAN_2.0.0_x64_en-US.msi
```

وقد تختلف أسماء الملفات قليلاً حسب إعدادات Tauri وإصدار البرنامج.

---

# 🟢 الطريقة الموصى بها للتثبيت

يفضل استخدام ملف:

```text
.exe
```

الخاص بـ NSIS Installer، لأنه الأنسب للمستخدم العادي ويوفر تجربة تثبيت مباشرة.

مثال:

```text
AMAN_2.0.0_x64-setup.exe
```

---

## 🧭 خطوات التثبيت

1. قم بتنزيل ملف تثبيت AMAN.
2. افتح مجلد التنزيلات.
3. انقر نقراً مزدوجاً على ملف:

```text
AMAN_2.0.0_x64-setup.exe
```

4. إذا ظهرت نافذة Windows تطلب السماح بتشغيل البرنامج، راجع اسم التطبيق ثم تابع.
5. اتبع خطوات معالج التثبيت.
6. انتظر حتى انتهاء تثبيت التطبيق.
7. بعد اكتمال التثبيت يمكن تشغيل AMAN من:

   * قائمة Start
   * اختصار سطح المكتب، إذا تم إنشاؤه
   * نتيجة البحث في Windows

# 🛡️ ظهور تحذير Windows SmartScreen

قد يظهر في بعض الإصدارات غير الموقعة رقمياً تحذير من Windows SmartScreen.

قد تظهر رسالة مثل:

```text
Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting.
```

هذا لا يعني بالضرورة وجود خطأ في التطبيق، وإنما قد يحدث لأن ملف التثبيت لم يتم توقيعه بعد بشهادة Code Signing موثوقة.

إذا كنت قد حصلت على التطبيق من المصدر الرسمي للمشروع وتأكدت من سلامة الملف:

1. اختر:

```text
More info
```

2. تحقق من اسم التطبيق.
3. اختر:

```text
Run anyway
```

> لا ينصح بتجاوز SmartScreen لأي ملف تم الحصول عليه من مصدر غير موثوق.

# 📦 التثبيت باستخدام MSI

يمكن أيضاً تثبيت البرنامج باستخدام ملف:

```text
.msi
```

وهو مناسب خصوصاً لبيئات Windows الإدارية أو المؤسسية.

مثال:

```text
AMAN_2.0.0_x64_en-US.msi
```

طريقة التثبيت:

1. انقر نقراً مزدوجاً على ملف MSI.
2. اتبع Windows Installer.
3. أكمل خطوات التثبيت.
4. شغل AMAN من قائمة Start.

# 🗂️ مكان تثبيت التطبيق

عند استخدام إعداد التثبيت الحالي:

```text
installMode: currentUser
```

يتم تثبيت التطبيق للمستخدم الحالي في Windows فقط.

ولا يحتاج المستخدم عادة إلى صلاحية Administrator كاملة.

قد يختلف مسار البرنامج الفعلي حسب نوع Installer وإصدار Windows.

---

# 💾 مكان حفظ بيانات AMAN

بيانات الخزنة لا تحفظ داخل مجلد المشروع أو بجانب ملف التثبيت.

يستخدم AMAN مجلد بيانات التطبيق الخاص بنظام Windows.

ويتم إنشاء ملف قاعدة البيانات باسم:

```text
aman_vault.sqlite
```

داخل App Data الخاص بالتطبيق.

---

# ⚠️ مهم جداً قبل إزالة البرنامج

قبل إلغاء تثبيت AMAN أو إعادة تثبيت Windows:

1. أنشئ نسخة احتياطية من الخزنة.
2. تأكد من إمكانية قراءة النسخة الاحتياطية.
3. احتفظ بها في مكان آمن.
4. لا تعتمد على أن إلغاء تثبيت التطبيق سيحافظ دائماً على جميع البيانات المحلية.

---

# 🔄 تحديث AMAN

عند توفر إصدار جديد:

1. أنشئ نسخة احتياطية من الخزنة الحالية.
2. أغلق AMAN بالكامل.
3. قم بتنزيل Installer الخاص بالإصدار الجديد.
4. شغل ملف التثبيت.
5. أكمل عملية التحديث.
6. افتح التطبيق.
7. تأكد من ظهور بياناتك السابقة.
8. اختبر إنشاء سجل جديد وحفظه.

لا تحذف قاعدة البيانات المحلية يدوياً أثناء التحديث.

---

# 🧹 إلغاء تثبيت AMAN

يمكن إزالة التطبيق من:

```text
Settings
→ Apps
→ Installed apps
→ AMAN
→ Uninstall
```

أو من:

```text
Control Panel
→ Programs
→ Programs and Features
```

ثم اختر:

```text
AMAN
```

واضغط:

```text
Uninstall
```

---

# ⚠️ حذف التطبيق لا يعني بالضرورة حذف البيانات

قد تبقى ملفات بيانات AMAN داخل مجلد App Data بعد إزالة البرنامج.

هذا السلوك مفيد في بعض الحالات لأنه يسمح بإعادة تثبيت التطبيق دون فقد البيانات.

لكن إذا كان الهدف حذف جميع البيانات نهائياً:

1. استخدم خيار حذف الخزنة من داخل AMAN إن كان متاحاً.
2. أغلق التطبيق.
3. أزل البرنامج.
4. تحقق من مجلد بيانات التطبيق.
5. احذف البيانات المتبقية فقط إذا كنت متأكداً أنك لم تعد بحاجة إليها.

> حذف ملف قاعدة البيانات أو مجلد بيانات التطبيق عملية غير قابلة للاسترجاع ما لم تكن لديك نسخة احتياطية.

# 🔒 توصيات بعد التثبيت

بعد تثبيت AMAN:

* استخدم PIN غير سهل التخمين.
* لا تشارك حساب Windows مع مستخدمين غير موثوقين.
* فعّل كلمة مرور أو Windows Hello للجهاز.
* احتفظ بنسخة احتياطية مشفرة.
* لا تنسخ ملف قاعدة البيانات إلى أجهزة غير موثوقة.
* لا تثبت تحديثات AMAN من مصادر غير رسمية.
* افحص اسم الإصدار قبل استبدال النسخة الحالية.
